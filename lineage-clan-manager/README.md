# 혈맹 관리 도우미

Windows PC에서 사용하는 혈맹 관리 프로그램입니다. 메뉴는 **혈맹원**, **레벨 랭킹**, **던전 전투** 세 가지입니다.

- 혈맹원: 캐릭터명·클래스·직책·레벨·경험치·메모 등록, 수정, 삭제와 검색
- 레벨 랭킹: 레벨과 경험치 순 정렬, 동률 공동 순위, 클래스별 조회
- 던전 전투: 참여자·전투 결과·보상·메모 기록, 수정, 삭제와 검색

사용자가 설명한 기능을 기준으로 만든 별도 프로그램입니다. 제작 환경의 네트워크 제한으로 원본 사이트 내부 화면·데이터와 대조하지 못했습니다. 원본 사이트의 계정이나 자료를 가져오지 않으며, 원본과 자동으로 동기화하지 않습니다. 처음 실행하면 빈 목록에서 시작합니다.

## Windows에서 실행하기

1. `LineageClanManager-1.0.0-windows-x64.zip`을 받습니다.
2. ZIP의 **압축을 폴더 전체로 풉니다**.
3. 압축을 푼 폴더 안의 `LineageClanManager.exe`를 두 번 클릭합니다.

설치나 별도 Node.js 설치 없이 실행하는 Windows 64비트용 배포본입니다. EXE 옆의 DLL 파일과 `resources` 폴더도 필요하므로 EXE만 따로 옮기지 마세요. 바로가기를 만들 때도 원래 폴더를 유지하세요.

자료를 수정하면 PC에 자동으로 저장합니다. 혈맹원을 목록에서 삭제해도 기존 전투 기록의 참여자 이름은 보존합니다. 레벨 랭킹은 입력한 레벨과 경험치를 사용하며 게임 서버에서 정보를 자동으로 가져오지 않습니다.

## 자료 백업과 복원

상단 **백업** 버튼에서 JSON 파일로 저장하고, **불러오기** 버튼에서 이 프로그램의 백업 파일을 선택하세요. 불러오기를 확정하면 현재 자료를 백업 내용으로 교체합니다. 필요한 경우 먼저 현재 자료를 백업하세요.

실제 자료는 프로그램 폴더와 별개인 `%APPDATA%\LineageClanManager\clan-data.json`에 저장합니다. Windows 탐색기 주소창에 `%APPDATA%\LineageClanManager`를 입력하면 저장 폴더를 열 수 있습니다. 프로그램을 다른 폴더로 옮겨도 같은 Windows 계정의 자료를 사용합니다. 다른 PC나 Windows 계정으로 옮길 때는 백업 파일을 함께 옮긴 뒤 불러오세요. JSON 백업은 읽을 수 있는 일반 파일이므로 본인이 관리하는 위치에 보관하세요.

## 소스를 수정하고 빌드하기

Node.js **22.12 이상** 또는 Node.js 24가 필요합니다. 프로젝트 폴더에서 실행하세요.

```bash
npm ci
npm run build
npm run desktop
```

`npm run desktop`은 현재 컴퓨터용 Electron이 설치되어 있어야 실행됩니다. `npm run dev`는 프런트엔드 개발 서버를 실행하며, 브라우저에서는 자료를 브라우저 저장소에 보관합니다. **브라우저 저장소와 Windows 프로그램의 자료는 서로 별개**입니다. 백업 파일로 옮길 수 있습니다.

Windows 64비트 배포본을 만들려면 다음을 실행하세요.

```bash
npm run package:windows
```

`release/`에 실행 폴더, ZIP과 SHA-256 확인 파일이 생성됩니다. 같은 버전의 완성 ZIP이 이미 있으면 덮어쓰지 않습니다. 새 배포를 만들 때는 `package.json`의 버전을 올리세요.

Linux에서 Windows 배포본만 만들고 Linux용 Electron 설치를 생략하려면 다음과 같이 설치할 수 있습니다.

```bash
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run package:windows
```

패키징은 공식 Electron Windows 런타임을 다운로드하고 체크섬을 검증합니다. 인터넷 접근에는 npm 레지스트리와 GitHub 릴리스 다운로드가 필요합니다. 사용자 자료·캐시·환경 파일은 배포본에 넣지 않습니다.

## 검증하기

```bash
npm test
npm run build
npm run test:browser
```

브라우저 검증은 Chromium 실행 파일이 필요합니다. 이 클라우드 환경의 기본 경로는 `/usr/bin/chromium`입니다. 다른 경로를 사용할 때는 `CHROMIUM_PATH`를 지정하세요. 테스트는 임시 자료와 별도 브라우저 저장소를 사용합니다.

배포 패키지의 Windows x64 실행 파일 구조, 앱 파일과 체크섬을 확인합니다. 제작 환경은 Linux이므로 **실제 Windows에서의 실행은 아직 확인하지 못했습니다**.

## 코드 위치

| 위치                          | 내용                                 |
| ----------------------------- | ------------------------------------ |
| `src/App.jsx`                 | 혈맹원·레벨 랭킹 화면                |
| `src/Dungeon.jsx`             | 던전 전투 기록 화면                  |
| `src/domain.js`               | 입력 검증과 순위 규칙                |
| `src/storage.js`              | 데스크톱 저장 연결과 브라우저 저장   |
| `electron/`                   | Windows 프로그램 창과 저장·백업 연결 |
| `lib/`                        | 로컬 자료 파일과 백업 검증           |
| `scripts/package-desktop.mjs` | Windows 배포본 생성                  |

외부 라이브러리의 라이선스는 `THIRD_PARTY_NOTICES.md`와 배포 폴더의 Electron 라이선스 파일을 참고하세요.
