# 혈맹 관리 도우미

Windows PC에서 사용하는 혈맹 관리 프로그램입니다. 메뉴는 **혈맹원**, **레벨 랭킹**, **던전 전투** 세 가지입니다.

- 혈맹원: 캐릭터명·클래스·직책·레벨·수기 순위·메모 등록, 수정, 삭제와 검색
- 레벨 랭킹: 입력한 수기 순위로 정렬, 순위 수정과 클래스별 조회
- 던전 전투: 수기 순위에 따른 상위 15명 또는 6개 클래스별 지정 인원으로 엔트리 편성, 체크·캐릭터명 입력으로 불참자 제외, 최종 명단 복사

사용자가 설명한 기능을 기준으로 만든 별도 프로그램입니다. 제작 환경의 네트워크 제한으로 원본 사이트 내부 화면·데이터와 대조하지 못했습니다. 원본 사이트의 계정이나 자료를 가져오지 않으며, 원본과 자동으로 동기화하지 않습니다. 처음 실행하면 빈 목록에서 시작합니다.

## Windows에서 실행하기

1. [LineageClanManager-1.3.0-windows-x64.zip](https://github.com/dlghkdyd21201-dotcom/WORK_1/raw/refs/heads/main/downloads/LineageClanManager-1.3.0-windows-x64.zip)을 받습니다. 파일 확인용 [SHA-256](https://github.com/dlghkdyd21201-dotcom/WORK_1/raw/refs/heads/main/downloads/LineageClanManager-1.3.0-windows-x64.zip.sha256)도 제공합니다.
2. 실행 중인 이전 버전을 종료하고 ZIP의 **압축을 폴더 전체로 풉니다**.
3. 압축을 푼 폴더 안의 `LineageClanManager.exe`를 두 번 클릭합니다.

설치나 별도 Node.js 설치 없이 실행하는 Windows 64비트용 배포본입니다. EXE 옆의 DLL 파일과 `resources` 폴더도 필요하므로 EXE만 따로 옮기지 마세요. 바로가기를 만들 때도 원래 폴더를 유지하세요.

자료를 수정하면 PC에 저장합니다. 게임 서버에서 정보를 자동으로 가져오지 않습니다. 수기 순위는 **1~5000 사이의 정수**로 입력하며 **숫자가 작을수록 높은 순위**입니다. 레벨 랭킹 화면과 던전 엔트리는 이 순위를 그대로 사용합니다. 같은 순위를 여러 명에게 입력할 수 있고, 동순위는 캐릭터명 순서로 표시·선발합니다.

순위를 비워 두면 **미입력**으로 표시하고 순위 입력자 뒤에 배치합니다. 미입력자끼리는 레벨이 높은 순서, 같은 레벨이면 캐릭터명 순서로 정렬합니다. 목록의 표시 순서로 새 순위를 만들어 붙이지 않습니다. 레벨은 계속 표시하며, 경험치는 입력·표시·순위 계산·최종 명단 복사에 사용하지 않습니다.

## 15인 엔트리 편성하기

먼저 **혈맹원** 메뉴에서 캐릭터명, 클래스, 레벨과 수기 순위를 등록하세요. 수기 순위는 비워 둘 수 있습니다. 던전 전투는 이 명단을 기준으로 엔트리를 만듭니다.

1. **던전 전투** 메뉴를 열고 불참할 혈맹원을 체크합니다. 또는 불참자 직접 입력에 **정확한 전체 캐릭터명**을 입력해 적용하세요. 여러 명은 쉼표 또는 줄바꿈으로 구분합니다. 입력으로 찾은 혈맹원은 기존 체크 목록에 합쳐지고 중복은 한 번만 반영됩니다. 찾지 못한 입력은 화면에 알리고 불참자에 추가하지 않습니다. 이름 일부로는 찾지 않습니다. 저장한 불참자는 두 선발 방식에서 모두 제외됩니다.
2. **랭킹 상위 15명**을 선택하면 참여 가능한 혈맹원 중 입력한 수기 순위가 높은 순서로 15명을 뽑습니다. 동순위는 캐릭터명 순서로 선발하며, 순위 미입력자는 입력자 뒤에 배치합니다. 선발 명단에 미입력자가 있으면 인원을 안내하며, 15명을 채웠다면 그대로 확정할 수 있습니다.
3. 클래스별로 인원을 정하려면 **클래스별 지정 인원**을 선택합니다. **군주 / 기사 / 요정 / 요정-똥물 / 다크엘프 / 마법사** 여섯 클래스의 숫자를 입력하고 합계를 **15명**으로 맞춘 뒤 **클래스별 인원 저장**을 누르세요. **요정**과 **요정-똥물**은 각각 별도 인원으로 계산합니다. 저장한 숫자는 다음 실행에도 유지됩니다. 각 클래스 안에서도 높은 랭킹부터 선발합니다.
4. 미리보기의 15명을 확인하고 **엔트리 확정·저장**을 누릅니다.
5. **최종 엔트리 복사**를 누르면 **캐릭터명 / 클래스 / 레벨**로 된 15명 명단을 채팅 등에 붙여넣어 전달할 수 있습니다.

참여 가능한 사람이 15명보다 적거나 특정 클래스의 지정 인원을 채우지 못하면 부족 인원을 표시합니다. 부족한 클래스를 다른 클래스로 임의로 채우지 않으며, 15명을 채우기 전에는 확정·복사할 수 없습니다. 불참 체크나 클래스 인원을 조정한 뒤 다시 확인하세요.

불참자, 선발 방식, 클래스 인원 또는 혈맹원 정보가 바뀌어 확정한 명단과 현재 선발 결과가 달라지면 다시 확정해야 복사할 수 있습니다. 확정 전에 이전 명단을 잘못 전달하는 일을 방지합니다.

## 이전 버전에서 1.3.0으로 업데이트하기

이전 프로그램을 종료한 뒤 **1.3.0을 새 폴더에 압축 해제해 실행**하세요. 같은 Windows 계정이라면 기존 PC의 혈맹원 자료와 설정을 이어서 사용합니다. `%APPDATA%\LineageClanManager` 폴더는 삭제하지 마세요. 업데이트 전에 자료 백업을 저장하면 별도 파일로도 보관할 수 있습니다.

**1.0.0·1.1.0·1.2.0 등 이전 버전 창을 먼저 완전히 닫아 주세요.** 버전 간에 하나의 실행 창을 공유하므로, 이전 버전이 실행 중이면 새 EXE를 눌러도 기존 창이 앞으로 나올 수 있습니다. 새 프로그램 왼쪽 아래의 버전이 **1.3.0**인지 확인하세요.

기존 혈맹원과 자료는 유지합니다. 이전 백업 변환본에 보관된 원본 자료가 있고 혈맹원에게 `manualRank` 항목이 아직 없으면, 같은 ID의 원본 순위 중 1~5000 사이의 유효한 정수를 수기 순위로 불러옵니다. 원본 순위가 없거나 유효하지 않으면 미입력으로 둡니다. 사용자가 순위를 지워 `manualRank: null`로 저장한 경우에는 원본 순위를 다시 채우지 않습니다. 기존 경험치 값은 이전 자료와의 호환을 위해 보존하며 화면·선발 기준·복사에는 쓰지 않습니다.

이전 방식으로 확정한 최종 엔트리는 새 수기 순위 기준으로 다시 확인하고 **엔트리 확정·저장**을 눌러야 복사할 수 있습니다.

이전 버전에서 현재 여섯 클래스에 없는 클래스 인원을 저장했다면, 던전 전투 화면에서 인원을 다시 배분하라는 안내를 표시합니다. 화면에는 현재 여섯 클래스의 입력값만 표시하고, 이전 클래스 인원을 다른 클래스에 자동으로 옮기지 않습니다. 합계를 15명으로 맞춰 저장하세요. 화면을 열었다는 이유만으로 기존 자료를 지우거나 덮어쓰지 않으며, 기존 혈맹원과 백업 자료도 유지합니다.

1.0.0의 백업도 불러올 수 있습니다. 이전 전투 결과 기록은 자료와 백업 안에 보존하고, **던전 전투 화면은 요청한 15인 엔트리 편성 기능으로 바꿨습니다**.

## 자료 백업과 복원

이전 웹사이트의 `nickname`·`job` 항목으로 된 백업은 기존 [백업 변환 도구 1.0.0](https://github.com/dlghkdyd21201-dotcom/WORK_1/raw/refs/heads/main/downloads/LineageBackupConverter-1.0.0.zip)로 먼저 변환할 수 있습니다. 이 변환본은 새 프로그램에서도 불러올 수 있습니다. ZIP을 풀어 `혈맹백업변환기.html`을 열고 원본 JSON을 선택한 뒤 **변환본 JSON 저장**을 누르세요. 만들어진 파일을 아래의 **백업 불러오기**에서 선택합니다. 이 도구는 인터넷 연결 없이 PC 안에서 처리하며, 파일을 서버에 전송하거나 원본을 덮어쓰지 않습니다.

변환기는 레벨이 비어 있으면 호환용 임시 Lv.1, 경험치가 없으면 호환용 0%를 보관하고 메모에 표시합니다. 새 프로그램에서는 경험치를 표시하거나 선발에 사용하지 않습니다. 원본 순위·활동 여부와 전체 원본 백업은 변환본에 함께 보존하며, 새 프로그램이 보관된 유효 원본 순위를 위 규칙에 따라 불러옵니다. `요정-똥`을 `요정-똥물`로 맞추는 옵션은 변환기에서 해제할 수 있습니다. 개인 데이터가 포함된 JSON은 공개 저장소에 올리지 마세요.

상단 **자료 백업** 버튼에서 JSON 파일로 저장하고, **백업 불러오기** 버튼에서 이 프로그램의 백업 파일을 선택하세요. 불러오기를 확정하면 현재 자료를 백업 내용으로 교체합니다. 필요한 경우 먼저 현재 자료를 백업하세요. 혈맹원과 함께 클래스 인원, 불참자, 확정 엔트리도 백업에 포함됩니다.

실제 자료는 프로그램 폴더와 별개인 `%APPDATA%\LineageClanManager\clan-data.json`에 저장합니다. Windows 탐색기 주소창에 `%APPDATA%\LineageClanManager`를 입력하면 저장 폴더를 열 수 있습니다. 프로그램을 다른 폴더로 옮겨도 같은 Windows 계정의 자료를 사용합니다. 다른 PC나 Windows 계정으로 옮길 때는 백업 파일을 함께 옮긴 뒤 불러오세요. JSON 백업은 읽을 수 있는 일반 파일이므로 본인이 관리하는 위치에 보관하세요.

## 소스를 수정하고 빌드하기

Node.js **22.12 이상** 또는 Node.js 24가 필요합니다. 프로젝트 폴더에서 실행하세요.

```bash
npm ci
npm run build
npm run desktop
```

`npm run desktop`은 현재 컴퓨터용 Electron이 설치되어 있어야 실행됩니다. `npm run dev`는 프런트엔드 개발 서버를 실행하며, 브라우저에서는 자료를 브라우저 저장소에 보관합니다. **브라우저 저장소와 Windows 프로그램의 자료는 서로 별개**입니다. 백업 파일로 옮길 수 있습니다.

Windows 64비트 배포본을 만들려면 다음을 실행하세요.

```bash
npm run package:windows
```

`release/1.3.0/` 아래에 실행 폴더가 생성되고, `release/`에 버전이 표시된 ZIP과 SHA-256 확인 파일이 생성됩니다. 이전 버전의 실행 폴더와 ZIP은 그대로 보관합니다. 같은 버전의 완성 ZIP이 이미 있으면 덮어쓰지 않습니다. 새 배포를 만들 때는 `package.json`의 버전을 올리세요.

Linux에서 Windows 배포본만 만들고 Linux용 Electron 설치를 생략하려면 다음과 같이 설치할 수 있습니다.

```bash
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run package:windows
```

패키징은 공식 Electron Windows 런타임을 다운로드하고 체크섬을 검증합니다. 인터넷 접근에는 npm 레지스트리와 GitHub 릴리스 다운로드가 필요합니다. 사용자 자료·캐시·환경 파일은 배포본에 넣지 않습니다.

## 검증하기

```bash
npm test
npm run build
npm run test:browser
```

브라우저 검증은 Chromium 실행 파일이 필요합니다. 이 클라우드 환경의 기본 경로는 `/usr/bin/chromium`입니다. 다른 경로를 사용할 때는 `CHROMIUM_PATH`를 지정하세요. 테스트는 임시 자료와 별도 브라우저 저장소를 사용합니다.

배포 패키지의 Windows x64 실행 파일 구조, 앱 파일과 체크섬을 확인합니다. 제작 환경은 Linux이므로 **실제 Windows에서의 실행은 아직 확인하지 못했습니다**.

## 코드 위치

| 위치                          | 내용                                         |
| ----------------------------- | -------------------------------------------- |
| `src/App.jsx`                 | 혈맹원·레벨 랭킹 화면                        |
| `src/Dungeon.jsx`             | 15인 엔트리 편성·불참자·명단 복사 화면       |
| `src/domain.js`               | 입력 검증과 순위 규칙                        |
| `src/storage.js`              | 데스크톱 저장 연결과 브라우저 저장           |
| `electron/`                   | Windows 프로그램 창과 저장·백업 연결         |
| `lib/`                        | 엔트리 선발 규칙, 로컬 자료 파일과 백업 검증 |
| `scripts/package-desktop.mjs` | Windows 배포본 생성                          |

외부 라이브러리의 라이선스는 `THIRD_PARTY_NOTICES.md`와 배포 폴더의 Electron 라이선스 파일을 참고하세요.
